# BigMart Sales Analytics using PySpark & Databricks

## Project Overview

This project implements an end-to-end Data Engineering pipeline using **PySpark, Databricks, Delta Lake, and Unity Catalog** to process and analyze BigMart sales data.

The project follows the **Medallion Architecture (Bronze, Silver, and Gold)** to ingest raw data, perform data cleaning and quality checks, and generate business-ready analytical datasets.

## Architecture

```text
             BigMart Sales CSV
                     |
                     v
              BRONZE LAYER
          Raw Data Ingestion
                     |
                     v
              SILVER LAYER
       Data Cleaning & Transformation
       - Missing Value Handling
       - Data Standardization
       - Duplicate Checks
       - Data Quality Validation
                     |
                     v
               GOLD LAYER
           Business Aggregations
                     |
          +----------+----------+
          |          |          |
          v          v          v
       Sales by   Sales by   Average Sales
       Item Type   Outlet    by Outlet Type
          |
          +----------+----------+
          |                     |
          v                     v
      Sales by             Top 10 Products
    Location Type             by Sales
```

## Project Implementation

### 1. Bronze Layer – Raw Data Ingestion

- Uploaded the source CSV file into a Databricks Volume.
- Read the CSV file using PySpark.
- Enabled header recognition and automatic schema inference.
- Stored the raw dataset as a managed Delta table.

**Table:** `bronze_bigmart_sales`

### 2. Silver Layer – Data Cleaning and Transformation

Performed data cleaning and quality checks using PySpark.

**Data Cleaning:**
- Standardized inconsistent Item_Fat_Content values:
  - LF and low fat → Low Fat
  - reg → Regular
- Handled missing Item_Weight values using median imputation (12.5).
- Replaced missing Outlet_Size values with Unknown because no trusted reference data was available.

**Data Quality Checks:**
- Checked NULL values across all columns.
- Verified duplicate records.
- Compared Bronze and Silver record counts.
- Validated the cleaned dataset before saving.

**Table:** `silver_bigmart_sales`

### 3. Gold Layer – Business Analytics

Created five business-ready analytical Delta tables.

| Analysis | Description |
|---|---|
| Sales by Item Type | Total sales for each product category |
| Sales by Outlet | Total sales generated by each outlet |
| Average Sales by Outlet Type | Average sales per dataset record for each outlet type |
| Sales by Location | Total sales across Tier 1, Tier 2, and Tier 3 |
| Top 10 Products | Ten products with the highest total sales across outlets |

**Gold Tables:**

- `gold_sales_by_item_type`
- `gold_sales_by_outlet`
- `gold_avg_sales_by_outlet_type`
- `gold_sales_by_location`
- `gold_top_10_products`

## Key Business Insights

- Fruits and Vegetables generated the highest total sales among item categories.
- Outlet OUT027 generated the highest total sales.
- Supermarket Type3 had the highest average sales per dataset record.
- Tier 3 generated the highest total sales among location tiers.
- Product FDY55 ranked first in total sales.
